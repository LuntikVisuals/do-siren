# До сирен

Короткая вертикальная 2D-игра вид сверху для телефона.

Клён-Хилл, Огайо. На участке дом с двором и особняк. Ты и четверо ботов. Роль выпадает случайно: выживший или киллер. Нужно дожить до сирен — или не дать остальным их дождаться.

Киллер ночи один из трёх, со своей способностью:

- **Джейсон Вурхиз** — «Ярость»: быстрее, ломает двери, бьёт больнее и видит всех.
- **Майкл Майерс** — «Взгляд»: тихий, копит наблюдение, потом кладёт с одного удара.
- **Крик** — «Плащ»: пропадает и метит жертву.

Живые: Майкл, Алиса, Дэнил. Сара и Джейк приходят ботами. В лобби — играть, магазин, персонажи.

## APK

Релиз собирается на GitHub Actions: HTML упаковывается во встроенный WebView (браузер телефона) и подписывается. Готовый файл лежит в [Releases](https://github.com/LuntikVisuals/do-siren/releases).

`com.luntikvisuals.dosiren`, versionCode 2, Android 7.0+. Поверх 1.0.0 встаёт та же подпись.
